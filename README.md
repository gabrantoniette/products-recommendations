A web application that recommends products to each user with a neural network trained in the browser using TensorFlow.js, based on their purchase history and age.

> This is a personal study project and is not production-ready.

## Project Structure

- `index.html` - Main HTML file for the application
- `src/index.js` - Entry point for the application
- `src/view/` - Contains classes for managing the DOM and templates
- `src/controller/` - Contains controllers to connect views and services
- `src/service/` - Contains business logic for data handling
- `src/workers/` - Web Worker that trains the model off the main thread
- `data/` - Contains JSON files with user and product data (fictional, generated by `scripts/generate-data.js`)
- `scripts/` - The generator for the fictional dataset

## Setup and Run

1. Install dependencies:
```
npm install
```

2. Start the application:
```
npm start
```

3. Open your browser and navigate to `http://localhost:3000`

4. The model starts training when the page loads, which takes a few minutes with 50,000 customers. When it finishes, select a user and click **Run Recommendation**.

## Features

- User profile selection with details display (the first 100 customers)
- Past purchase history display
- Product listing with "Buy Now" functionality
- Purchases added in the page are kept in memory until it reloads
- Model training in a Web Worker, with live loss and accuracy charts in tfjs-vis
- Products ranked for the selected user by the trained model

## The Data

`data/` holds 25 products and 50,000 fictional customers, 20% of them with no purchases. `npm run generate` writes both files again; the seed is fixed, so the output is always the same.

Random purchases would leave the model nothing to learn, so the generator gives each customer hidden tendencies and draws their purchases from them, with noise:

- Age leans toward categories: under 30 toward electronics and footwear, 30 to 49 toward clothing and electronics, 50 and over toward accessories and clothing.
- Each customer has a budget that grows with age and prefers products priced near it.
- Each customer has two favorite colors.

The tendencies never go into the JSON files: the model only sees what each customer bought.

## How the Recommendations Work

1. Each product becomes a weighted feature vector: normalized price, normalized average age of its buyers, and one-hot category and color. Category weighs 0.4, color 0.3, price 0.2 and age 0.1.
2. Each user becomes the average of the vectors of the products they bought. A user with no purchases is represented by their normalized age only.
3. Every user and product pair is a training example, labeled 1 if the user bought the product and 0 if not: about a million pairs. For a product the user bought, the user vector is the average of their *other* purchases (or their age alone, if it was the only one). With the full average, the product itself sits inside the user vector, and the model learns to spot what is already in the history instead of the taste behind it.
4. A small dense neural network (one hidden layer of 32 units, then a sigmoid output) learns to predict that label with binary cross-entropy, in 10 passes over the data in batches of 512.
5. To recommend, the model scores every product for the selected user. The products they already bought go to the end of the list, and the rest are sorted from highest to lowest score.

## How It Was Measured

One purchase was hidden from 5,000 customers with two or more purchases, the model was trained without it, and the test checks where the hidden product lands among the products that customer does not have yet. Three training runs per setup, same data and same settings:

| Setup | Hidden purchase in the top 5 | In first place |
|---|---|---|
| Random order | 23.6% | 4.7% |
| Best sellers first (no model) | 35.6% | 9.0% |
| 128 → 64 → 32, user vector with the product inside | 33.2% | 7.9% |
| 32 units, user vector with the product inside | 33.8% | 8.2% |
| 128 → 64 → 32, user vector from the other purchases | 43.1% | 12.2% |
| **32 units, user vector from the other purchases (this code)** | **42.0%** | **11.7%** |
| Ranking by the generator's hidden tendencies (ceiling) | 58.6% | 22.5% |

What the model sees in training mattered far more than its size. The 32-unit network has 1,025 weights against 14,337 and trains faster, for about 1 point less in the top 5. On the first dataset of 5 customers and 50 pairs, the 128 → 64 → 32 stack memorized the training pairs and scored every hidden purchase close to 0.
